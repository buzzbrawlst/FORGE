# FORGE — OG Island

A free, browser-playable **original OG-era battle-royale sandbox** made with Three.js/WebGL.

## Play
Open the GitHub Pages site for this repository. No install or paid server is required.

### Controls
- WASD — move
- Shift — sprint
- Space — jump
- Mouse — look
- Left click — shoot
- Q — build a wooden wall
- 1 / 2 / 3 — switch weapons
- Esc — menu

## What is it?
FORGE is an original browser prototype inspired by the feel of classic 2017-era battle royale games: an island, loot, bots, shooting, building and a simple HUD.

It does **not** contain Epic Games' Fortnite client, proprietary game files, or Fortnite assets.

## Tech
Static HTML + JavaScript + Three.js CDN. Designed for Chrome and Chromebook.
